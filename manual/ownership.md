# Column Ownership
## Introduction
Columns in CoSMA-Editor are either curated or belong to an individual user.
The former are called curated columns and latter are called user columns.
The owner of column *C* is able to change its values and review merge request that have column *C* as destination.
It is possible to change the owner of a column.
This is helpful, when a someone joins or leaves your research group.

## Create an Ownership Request
1. Enable the column for viewing in the **View** section of CoSMA-Editor.
2. When hovering the cursor over the header menu of the column, a small triangle will appear. Click on it
3. Select **Change Owner**
4. Search for the name of the user you want to transfer the ownership to
5. Click on the name of the user

## Accept an Ownership Request
The column belongs to the original owner until the ownership request is accepted.
1. Go to the **Column** section of CoSMA-Editor
2. To retrieve ownership for a column click on **Accept** in the corresponding ownership request.

## Withdraw an Ownership Request
If you created an ownership request unintentionally, you can withdraw it.
1. Go to the **Column** section of CoSMA-Editor
2. To retrieve ownership for a column click on **Withdraw** in the corresponding ownership request.
